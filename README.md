# Rune Rush Crown Cup —— PICO XR

This public repository is the release landing page for the PICO XR edition of Rune Rush Crown Cup a first-person fantasy item racing game.

## Downloads

The complete publicly distributable Unity source snapshot and the final Android APK are attached to the **v1.0.0-pico** GitHub Release. The source archive is generated from the locally audited source commit 29615ac0a375c6a2df44e0271b6b1b27a52613c0.

The PICO SDK build cache logs APK build folders and all signing material are intentionally excluded from source control and release source archives. Install a matching PICO XR SDK from its official channel at Packages/com.bytedance.pico.xr before opening the Unity project.

## PICO controls and comfort

- Right index trigger accelerate.
- - Right Grip nitro the desktop Unity equivalent is Shift.
  - - The camera is fixed at the cockpit driving position. The car follows the track while headset tracking provides natural free head observation gameplay input never translates the headset view.
    - - Menus race HUD pause and results use a World Space UI with a unified 2x scale.
